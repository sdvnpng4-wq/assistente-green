# Assistente Green

Aplicativo Android com assistente flutuante, movível e ocultável.

## Gerar APK
1. Abra a aba **Actions** deste repositório.
2. Execute **Build Android APK** em **Run workflow** (ou envie um commit).
3. Quando terminar, abra a execução e baixe o artefato **assistente-green-debug-apk**.

## Estado atual
Esta é a primeira base funcional: pede permissão de sobreposição e inicia uma bolha flutuante que pode ser arrastada, aberta e fechada. A conversa com IA e a integração com Discord ainda precisam ser conectadas; não há chave de API incluída no app.
